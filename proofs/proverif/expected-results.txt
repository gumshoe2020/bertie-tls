# One line per query in analysis.pv order: number, ProVerif result, meaning.
# Result `false` on a reachability query means the event IS reachable (the model is not vacuous).
1 false reachability: client can finish the handshake (guard: must stay false)
2 false reachability: server can finish the handshake (guard: must stay false)
3 false server authentication fails if the certificate key is compromised (expected attack)
4 true server authentication holds unless the certificate key is compromised
5 false session-key secrecy fails if the certificate key is compromised (expected attack)
6 true session-key secrecy holds unless the certificate key is compromised
7 true harvest-now-decrypt-later: client keys stay secret unless the certificate key was compromised earlier
