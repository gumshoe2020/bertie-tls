# Contributing to bertie-tls

Contributions from people and agents working under a person’s direction are welcome.
Read [AGENTS.md](AGENTS.md) for scope, correctness rules, AI disclosure and checks.
Keep changes small, explain the behaviour and trust boundary, and include the checks you ran.
See [COVERAGE.md](COVERAGE.md) for measured proof scope and the coverage ratchet.
Discuss new algorithms, extensions or public API changes with a maintainer first.
